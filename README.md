# [Wallete](https://carlexandre.github.io/Wallete/)

Wallete é um gestor financeiro pessoal **simples, moderno e mobile-first**, criado para facilitar o controle de gastos e rendimentos do dia a dia. O projeto foi desenvolvido como uma **Single-File Application (SFA)**, eliminando processos complexos de instalação e permitindo uso rápido e direto.

---

## Funcionalidades

### Gestão de Fluxo de Caixa
- Registre **Entradas** (salários, freelances, rendas extras).
- Controle **Saídas** (contas fixas, lazer, despesas variáveis).

### Recorrência Inteligente
- **Fixas**: despesas que se repetem automaticamente todos os meses.
- **Parceladas**: defina o número de parcelas (ex: 12x) e o sistema faz a contagem regressiva automaticamente.

### Categorias e Sub-itens
- Organize seus gastos por **categorias principais** (ex: Casa).
- Detalhe cada categoria com **sub-itens** (ex: Aluguel, Luz, Internet).

### Dashboard Visual
- Barra de progresso que compara **Renda vs. Gastos** em tempo real.
- Visão clara e rápida da sua saúde financeira.

### Sincronização na Nuvem
- Todos os dados são salvos no **Google Firebase**.
- Acesse suas informações de qualquer dispositivo, com segurança.

### Modo Escuro
- Interface moderna com **Dark Mode** e estilo **Glassmorphism**.
- Experiência visual confortável e elegante.

---

## Tecnologias Utilizadas

- **Frontend:** React.js (via CDN) + Babel
- **Estilização:** Tailwind CSS
- **Backend / Database:** Firebase Firestore & Firebase Authentication
- **Ícones:** Lucide Icons

---

## Foco do Projeto

- Experiência otimizada para **dispositivos móveis**.
- Simplicidade, performance e usabilidade.
- Ideal para quem quer controlar finanças sem burocracia.
